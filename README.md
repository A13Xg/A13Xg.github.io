# a13xg.github.io

Root GitHub Pages site for A13Xg Industries.

- `app-ads.txt` — authorized ad sellers (IAB spec), crawled by AdMob at `https://a13xg.github.io/app-ads.txt`. All apps whose App Store / Play developer website is on `a13xg.github.io` share this one file; add a line per ad network/publisher ID.
- `index.html` — redirects to the app docs at `/App-Documentation/`.
